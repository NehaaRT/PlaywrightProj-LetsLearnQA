Implement CI using GitHubActions in Page Object Model
----------------------------------------------- 
1]GitHub Actions is a Continuous Integration and
2]Continuous Deployment (CI/CD) platform built directly into GitHub.
3]In Playwright, a .yml (or .yaml) file is most commonly used to configure Continuous Integration (CI)pipelines,
4]allowing your automated end-to-end tests to run automatically whenever code is pushed.
5]Instead of just writing tests that run on your laptop,

A]GitHub Actions lets you tell GitHub:
  "a]Every time I push new code or open a pull request,
   b]spin up a virtual computer in the cloud,
   c]download my project, 
   d]and run my automation suite."
